# A03 入口台阶

原 A03 入口台阶高于角色既有的 0.12 米跨阶高度。使用主地图 Terrain、原 Mage 控制器和相同输入路线复现：角色前进 0.474 米后被第一阶挡住，连续两秒没有进展。

修复在三段原石阶前补入可见的中间踏步，沿用 A03 的 M002 石材。保留原 26 个碰撞体、75 个渲染器、原建筑尺寸及场景实例的位置、旋转和缩放；增加三个踏步和对应 BoxCollider，并加入三个 LOD。新增前缘从局部 z=2.980404 延伸到 3.15，LOD 参考点随边界重新计算。不能按新包围盒重新居中现有场景实例。

`RuralA03EntrySteps.Ensure` 已接入 `RuralAssetImport` 的 A03 导入分支。重复执行不会叠加台阶；已有台阶被人工修改时拒绝覆盖。原生检查涵盖连续调用、保存重载后再次调用、原组件与根姿态保留，以及与已验证 prefab 的结构等价。
