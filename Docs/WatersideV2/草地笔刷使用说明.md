# 草地笔刷使用说明

Unity 菜单 **天气屋 → 地形与植被 → 局部草地笔刷**。窗口指定场景里的草地对象，首次点击“为这片草地启用局部编辑”，再点击“启用 Scene 草地笔刷”。工具只在退出 Play 后可用。

| 模式 | 怎么操作 | 主要参数 |
| --- | --- | --- |
| 擦草 | 选一种草或“全部草种”，在 Scene 左键拖动 | “擦后剩余密度”0 为擦净，0.5 保留约一半；半径、边缘硬度、作用强度控制范围和过渡 |
| 铺草 | 选主草地的短草、高草、雏菊，或植物库预设，左键拖动 | 新增密度按“丛 / ㎡”；可调整高度、草丛宽度。植物库有 20 个预设、13 种形态，包含不同长度的草 |
| 圈定后调整 | 选具体草种，在 Scene 按下圆心、拖出圆形范围；松开后调参数，点击“将参数应用到圆选区” | 分别勾选密度、高度、草丛宽度；没有勾选的参数、其它草种和选区外保持原样 |

外圈表示笔刷范围，内圈表示满强度范围。边缘硬度越低，向周围的过渡越柔和。圈定后还可以用半径滑条改范围；圈定和拖动参数本身不会写入草地。

高度倍率缩放整丛的纵向尺寸，**草丛宽度倍率缩放整丛的水平范围，并非单独改变每片叶子的宽度**。1 倍沿用所选草种的尺寸。局部调参的高度、宽度以原尺寸为基准；密度倍率乘在当前数量上。反复应用密度会继续相乘，想比较不同参数可先撤销再应用。

- **Shift + 左键**：临时擦草，使用擦草页设置的剩余密度。
- **Alt**：保留 Scene 视角导航。
- **Esc**：结束当前笔触并关闭笔刷，已刷的内容保留；想取消已刷内容可撤销。
- **Ctrl/Cmd + Z**：撤销；**Ctrl/Cmd + Shift + Z**：重做。一次按下至松开是一笔。窗口按钮与 Unity 共用撤销顺序，若随后改过其它物体，会先撤销该物体。

笔触存在目标草地的 `GrassLocalPainter` 组件，随场景保存。点击“保存此场景及草地笔触”会同时保存**该场景其它尚未保存的更改**，不自动保存其它场景。

笔刷覆盖原主草地和笔刷新增的草，保留原草种资产、材质和覆盖图。手工摆放的植被物件、树、道路和水体不属于草刷编辑范围。落点使用目标 Terrain，石桥或悬空平台上的植被仍通过物件摆放调整。

铺同一草种的新增草时，再刷同一区域会按当前新增密度更新，不按鼠标事件数量重复堆叠。不同草种可以叠种；原有草地上的新增草会与原草同时显示，要替换原草可先擦除再铺。

草种列表保留水岸的加厚“奶白实体长穗”，另有“植物库原型 / 奶白羽穗草”可选，两者是不同形态。
