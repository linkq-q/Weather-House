# 新增房屋屋顶材质统一

新增 A01—A09 的屋顶与现有天气屋材质不协调：苔藓三种材质的明暗分块较强，瓦片反光也较硬。本次调整 90 个屋顶材质，其中 27 个苔藓材质复用当前天气屋的油画色块着色器及参数，主、亮、暗仅保留 1、1.04、0.96 的小差异；63 个瓦片材质保留原七种配色差异，采用天气屋色调，光滑度由约 0.09 调整到 0.02255。

墙面、木材、玻璃、金属、模型、UV、摆放和碰撞未改。原天气屋的贴图使用不同 UV，未直接套到新模型上。导入器按已有材质语义应用同一规则，重导入会重新从源配色计算，不累计乘色。

A09 苔藓包含开放薄面，继续保留双面显示。共享 Painterly Ground 着色器仅新增材质剔除选项，默认仍为 Back；旧天气屋苔藓和两个地面材质保持原剔除方式。
