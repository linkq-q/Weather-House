# 河口木桥入口

原海岸路线在木桥东岸入口卡住。桥面比岸面高约 0.3301 米，超过原角色 0.12 米跨阶高度；原胶囊扫掠命中末端踏面 38。保留桥的位置、模型、55 个原碰撞体及角色参数，新增三块与原桥同材质、同宽度的木踏面，将高度分成四级，每级约 0.0825 米。

构建器只有一行新增调用。编辑工具按真实末板和岸面生成踏面，重复执行不改变结构；手动修改过的踏面会被保留并提示检查。没有新增运行时脚本。
