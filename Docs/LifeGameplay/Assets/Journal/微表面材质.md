# 纸纤维与布纹微表面

保留 `PaperAged.png`、`CoverAged.png` 的原始彩色像素，独立生成纸纤维与交织布纹。花朵和封皮印花没有参与高度计算，因此不会变成浮雕。

`Tools/LifeAssets/bake_journal_micro_surfaces.py` 在 Blender 5.1 的 Cycles 中将程序凹凸烘焙为切线法线，源节点保存在 `Tools/LifeAssets/Source/JournalMicroSurfaces.blend`。纸张使用两个方向的拉长噪声，封皮使用两个方向的交织波纹与少量噪声；有效高度为亚毫米级。四张纹理均为 1024×1024：

- `PaperAged_Normal.png`、`CoverAged_Normal.png`：切线 +Y（OpenGL / Unity）法线，Unity 导入为 NormalMap。
- `PaperAged_AO.png`、`CoverAged_AO.png`：线性灰度的浅纹理缝隙与边缘遮蔽。它们由程序遮蔽场以 Emission 烘焙，不是整本书几何的光线追踪 AO；深书沟由几何、法线与运行时材质表现。

纹理都位于 `Assets/Game/Life/Art/Resources/LifeAssets/JournalTextures/`。法线和 AO 使用原纸面 UV0，正文 RenderTexture 的裁切只应用于 BaseMap，避免文字裁切同时改变纤维尺寸。实际 Unity 强度与导入接线由 `LifeArtImporter`、`LifeJournal3D` 和 `JournalSurface` 管理。

已实际烘焙并渲染展开、封面、微表面细节，以及相同机位的无微表面／仅法线／法线加遮蔽对照。`micro-surface-bake.json` 记录像素范围，`micro-surface-render-check.json` 记录对照差异；法线独立渲染的平均通道差异为 0.00135，法线加遮蔽为 0.00218，说明实际参与渲染且整体变化轻微。预览已查看，纸面保持清晰、布纹不覆盖印花。这是 Blender 材质证据，Unity 的实际显示与交互由主任务另行记录。
