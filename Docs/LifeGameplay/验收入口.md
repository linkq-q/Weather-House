# 天气屋玩法验收入口

分支：`codex/full-gameplay-20261026`。正式入口：`Assets/Scenes/WeatherHouse_WatersideV2.unity`。

## 本轮约定

- 先近距离交谈，玩家解释动物字语，真实 AI 确认理解之后，才出现该请求的帮助任务。
- 天气始终作用于玩家身边的圆形范围；观察、提前改变天气、错误解释都不能完成未接受的帮助。
- 帮助任务、动物关系与字义分别记录。摄影修订采用 31 个完整词，想要／不想要开场已知，22 个拍照任务与 4 个互动情境奖励其余词义。拍照奖励直接标注短中文含义，不经过 AI 猜义门槛；天气手势在手账里练习后才能施放，雨和停止天气直接开放教学。
- 右上角无任务时隐藏；不常驻显示“生活 0/9”“字典 2/24”等计数。详细帮助由 H 主动展开。
- J 手账使用保留原画设计的 Blender 实体书，正文随真实纸页开合、翻动；静止后恢复输入和照片操作。
- 保留牧场动物；渡口新增两只身份固定的关键动物，复用原有正式模型，承担渡口／潮池对应教学。

## 从新档检查

1. J 打开手账，进入天气手势页，看示范并按住鼠标左键画雨手势。练习成功后合书，G 进入施法，画出雨；Esc 退出描画。
2. 近距离 E 听动物的话，用中文解释它的意思。错误或含糊的回答不能出现任务；正确解释后只显示这一具体请求。
3. 在动物附近完成请求。地图上选定的同类植物均可靠近按 E 采集；任意来源的同种草都能使用。F 拿取、持草编垫、铺放或邀请；Shift+F 收回垫子或倒空水碗。明确指路、回家等请求仍保留目的地含义。
4. C 打开相机、空格拍照，风景和没有动物的画面也能保存。在 J 的相机页签翻看摄影任务；同一照片可以完成多个任务，已知词直接显示短含义。原照片保留当时的公开语境，互动情境则有独立记录。
5. 确认新字后回手账学习对应手势；验证没有凭猜义或打开页面自动解锁。
6. 回访原动物，检查物件和已确认字保存；完成过的帮助不会因再次淋湿而抹去。

## 存档失败修复

自动检查复现 Windows/Unity Mono 在第二次覆盖存档时返回 `0x80070497`（1175）。生活存档和词典现在共用 `LifeSaveFile`：先在同目录写临时文件，正常使用 `File.Replace`；仅遇到该 Windows 错误时改用同卷 `MoveFileExW` 替换。其他错误继续上报，不先删除旧档。错误含义与替换标志依据 [ReplaceFileW](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-replacefilew) 和 [MoveFileExW](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-movefileexw)。宿主 CLR 检查与实际 Unity Play 检查分开记录，不据此宣称断电恢复已经验证。
