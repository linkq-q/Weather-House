# 手账与施法

正式水岸场景由 LifeSession 接入。保留原照片与字形布局；J 手账以 Blender 实体书呈现，开合与翻页使用骨骼动画。旧 MapDraft 继续使用原有操作。

## 操作

| 操作 | 按键 |
| --- | --- |
| 手账及学习手势 | J，选择上方第三个太阳页签 |
| 近距离交谈 | E，中文输入后 Enter；输入法选词 Enter 不发送 |
| 换一句动物话 | 对话上方「再听另一句话」 |
| 世界描画 | G，再按住鼠标左键，一笔描画；松开提交 |
| 取消 | Esc；J/C/E 切模式也清除未完成笔迹 |
| 拍照 | C，空格拍摄 |
| 物件 | F |
| 引导 | H 展开或收起当前阶段的一句提示 |

雨与收起天气开放教学。日照、风、弱、强在相应字正式确认后才开放练习。每个手势完成一次轨迹练习后才能用于世界，练习本身不调用天气。其他字的确认仍按语言证据规则执行。

首次确认新的天气字会出现一次「手账里有新手势可学」。字库格用纸底颜色表达状态：绿色未拍到、蓝色已拍到、黄色已理解；不再用常驻圆环或中文标签表达状态。悬停时显示绿色描边；已理解字还会在右上方复用动物聊天气泡显示简短释义。

天气围绕玩家当前所在位置，施法不选择远方动物。是否理解动物并接到任务、是否处于帮助距离、是否满足任务条件由 LifeSession/LifeWorld 独立校验。观察不会自动领取帮助。

## 手势规则

六个手势均为单笔，方向和起点固定，平移和等比缩放自由，绘制速度不参与识别。金色笔尖会反复演示先后顺序；书页保留练习、重试、回到对应字证据的入口。

| 手势 | 轨迹 |
| --- | --- |
| 雨 | 上端向下直线 → 左上回折 → 回到底端 → 右上收笔 |
| 收起天气 | 左上向右横线 → 左下斜线 → 向右横线 |
| 日照 | 圆顶开始，顺时针完整一圈 |
| 风 | 从左向右两道波浪，先上后下 |
| 弱 | 左上 → 中下 → 右上 |
| 强 | 左下 → 中上 → 右下 |

## Unity 中的验收路径

1. 从正式水岸入口新档进入。J 中没有样例照片；想要/不想要属于开场已知，其余字格以绿、蓝、黄纸底分别表示未拍到、已拍到、已理解。悬停显示绿色描边，只有已理解字显示释义气泡，状态与词典一致。
2. 在书内练习雨。倒画、半画、乱画不能学会；正确轨迹学会但天气不变。关闭书后 G 描画雨，范围圈与局部天气出现；1/2/3 无法绕过学习。
3. 起笔后按 Esc/J/C/E、失焦、关闭 HUD，检查笔迹消失、角色输入恢复；中文输入、拍照与书页不触发世界施法。
4. 右上只显示 AI 确认后的具体帮助任务；无任务时不显示。每页两个目标，包含动物名和距离，超过两个可点上一页/下一页。观察、问候、判错、超时、话轮改变不应接任务。界面不常驻剧情或词典计数；H 由玩家主动展开提示。
5. 拍照后让动物移动。相册展示拍摄开始时的角色名、地点名和物件状态；原坐标仍保存在快照中，画面不显示XYZ或内部语义ID。缺失照片有提示，手动播放结束后可重播。
6. 在晴/阴/夜、不同分辨率观察笔迹与范围圈；检查动物和字语可读性、地形贴合、透明排序；连续进出书页/施法50次检查材质数量与帧耗。
7. J 打开时，封面展开的后半程已有四张独立薄页松开成扇形；随后各自以不同进度错时翻落，总翻落阶段约 0.74 秒。前导版式始终是左侧四张未拍照占位图、右侧原字形格；最后一张翻动时才逐渐露出原先选中的照片、手势或任务内容。普通手动翻页仍为 0.9 秒，文字与照片贴着纸面移动。页签在翻页期间保持不透明，只有整本开合时淡入淡出。中途 J 可反向开合，自动翻落期间 J/Esc 会等这组纸页落下再合书，再按 J 可撤销关闭。左右箭头翻页方向相反。静止后，文字输入、照片放大播放、鼠标练习恢复交互。动画中不能点透或描画。

自动检查入口：`Weather House/Life/Check gesture recognition`，另外检查两个 Shader 的 Resources 引用与当前设备编译错误、真实笔迹顶点，以及实体书模型、双面纸材质、Unity 实际采样后的开合与弯曲。初轮 Play 发现的范围圈 HLSL 保留字错误已修复；最新 UI Play 自动检查已通过，轨迹、书页和透明渲染的实际观感仍待人工验收。

`LifeUiPlayChecks.Run(life, completed)` 由根 Play 验收在隔离存档中调用：检查快速J反向、翻页时Esc、详情宽高适配、缺图、50次重建材质与RT数、四页签同排和透明交互面的实际UI射线。它另外生成独立测试PNG，执行20次词条开关、20次18帧播放和9张封面翻页，记录实际解码次数、书对象是否保留、缓存上限与关闭释放；动物气泡热切20次检查气泡和字形槽实例复用。播放的到期时间由测试推进，不代替正常录制/回放和人工输入验收。测试生成的文件会在隔离目录内逐个删除。

详情层独立开关，书本对象保留。照片最多缓存8张封面与当前短片的18帧，关J时统一释放；动物泡保留一个根对象，字形槽只在长度超过此前最大值时增加。源码编译通过不等于这些热路径已经在Unity通过，结果以本轮Play报告为准。

`LifePersistencePlayChecks.Run(life)` 在隔离存档的唯一子目录内用同名 `.tmp` 文件夹阻塞真实写入，经实际 AI 结果回调验证「理解成功、任务仍在内存、明确提示生活进度写入失败」，然后恢复环境与运行状态。它不调用远端服务，也不接触 API 配置。

纸页与封皮材质接入 `PaperAged_Normal/AO`、`CoverAged_Normal/AO`：法线以 NormalMap 线性导入，AO 为线性灰度；FBX 计算 Mikk 切线。运行时正文截图只改 BaseMap 裁切，法线/AO继续使用完整单页UV。固定柔光与AO总明暗不低于0.80，避免世界光曝光影响照片和文字。应在四贴图导入后强制重导入 JournalBook.fbx，再用编辑检查核对纹理类型、切线、材质绑定，用Play检查动态页依然保留正确细节纹理。
