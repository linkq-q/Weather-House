这次设想的故事动机和手账教学比昨晚方案完整。需要收住的是连续讲解、反复自动开书，以及“三只动物”变成地图搜集门槛。明确告诉玩家操作方法不会破坏氛围；提前翻译未知动物语、让玩家照抄答案，会削弱发现感。

推荐顺序
开场电影落到玩家 → J 认识奶奶的书、四页签与想要／不想要 → 相遇你好、分别再见成对观察 → 猜两个字并演示一次线索 → 摄影挑战页 → C 拍说话动物 → 按字回看真实上下文 → 雨练轨迹 → 近谈理解请求 → G 真实施雨 → 学并施放收起天气 → 再见、自由拍照与回访。

开场
岛名主推“雾汐岛”，备选“隐潮岛”“听岚岛”，均待定。约 50 秒的 16∶9 安全构图，经过全岛、中央小岛和天气屋、牧场、林地与湿岸，最后落在正式初始相机。讲述天气家族与动物互惠数百年、全家赴魔法会议、奶奶留下手账、暂由小魔女照料。头顶语泡保留“可是我还什么都不会啊！”。建议理解为未独立照料、不会动物语，避免马上学会照轨迹施雨显得自相矛盾。开场可暂停、跳过、重看文字，支持减少运镜。

你好／再见
成对观察和比较，分别判词；不要 hello 正确就顺便给 goodbye。三只指三个不同个体，不要求三种物种。主推形成一对清楚语境后即可继续，第三只作可选对照。相遇与离开要有稳定距离内外圈、停留时间和个体冷却，不能在边缘反复刷语泡与进度。同动物反复相遇不发新字或线索。玩家离开，留下的动物同样会道别。

书里填词用什么判断
不建议每次都调用 AI。常用同义词本地判，例如你好／打招呼／问候、再见／告别／拜拜；自由长句交 AI 结合真实已见语境判断。结果分为含义相符、含义不符、还不够明确／服务不可用。网络失败不算错，不消费线索。当前书内“记下来”只保存猜测，没有判对错；这是本版提出的新机制。书内确字也不能代替对动物当前请求的理解。

线索
hello 第一次有效猜测不符后亮一次教学线索，“和朋友相遇时，常说的第一句话？”教学机会不扣普通库存；猜对者不必故意答错。之后每 3 个首次确字获得 1 次，开场赠予 want／reject 不计，重复拍照／读档／重放不计。已看的同一条可免费重看，操作帮助和回看证据始终免费。文案宜鼓励观察，不强调“别浪费”。

摄影与猜词不冲突的做法
保留当前 P20／P21 照片可确认你好／再见的规则。推荐先猜首对字，再教相机；提前拍到或旧档已确认就略过对应猜词，不压住奖励，不撤回已知字。首张说话照片只要求学会记录真实话语，不保证就是问候任务。实际任务名应对应动物语本义，如 P20 你好、P21 再见、P05 雨、P06 水；文学句适合作地点批注。

照片语境
当前按字只筛相关照片，尚不是所有未拍对话。提案是一处上下文视图，分清照片片刻与现场记录，只收玩家实际见到的历史，不补造画面。颜色要配状态文字；绿灰未有照片、蓝灰有照片未确认、暖黄已确认，写猜测不直接变黄。

必须先修好的入口
用户反馈书中天气手势无法描画，不能用源码有练习垫或新教程文案当作修复证据。实际鼠标按下、拖动、释放、笔迹、正确／反向／取消、书与世界互斥都需要真实验证。
