01 · 固定站位与转身受阻，分别处理

原问题

闲时短租约被持续续约

原 LifeWorld 每 0.5 秒给全部 Binding 续约 1.5 秒的同一目标，初始目标为 home。WildlifeAgent.Think 发现 HasLifeTarget 就提前返回，动物抵达后仍无法恢复普通自然决策。

已实施

按实际控制需要续约

休息、饮水、天气退避、演示和明确邀请继续由原控制器行动。对应动物的 Active 帮助任务、对话或理解判定期间，以当前身位驻留；空闲时不再续约，原短租约到期后恢复原有生活。

本轮补齐

保留朝向，寻找能退让的目标

Ambient 地面动物在打招呼后，邻居可能挡住原地转身。首次候选验证失败后，追加以当前朝向验证同一候选的完整移动段；通过才选为目标。原移动器本来已有短步不转身退让，这次让选点阶段也能使用这种安全出口。

次级个体原本已有种子随机、待机、觅食、社交、惊扰与返回群落逻辑。本次没有替换整个行为系统。普通地面自由巡游取点从 0.6R 扩至 0.9R，目标仍须位于原 habitatRadius 内并通过原可达性检查；Solitary 与 JourneyHerd 继续使用各自原路径。
