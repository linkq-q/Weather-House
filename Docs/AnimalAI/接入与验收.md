# 动物 DeepSeek 行为第一版

2026-10-29。运行入口是 WatersideV2 的 `LifeWorld.Initialize`，Play 时自动建立 `AnimalAutonomy`，登记普通陆地动物和 JourneyHerd 成员，不需要修改场景或挂组件。

## 使用

1. 打开 `WeatherHouse_WatersideV2`，重新进入 Play。
2. 在编辑器顶部菜单选择 **Weather House → Animal AI → Show Runtime Status**，Console 会显示动物数量、外向数量、请求数和有效回复数。该入口不在游戏 HUD。
3. 本机配置在 `UserSettings/WeatherHouseAnimalsAI.json`，已被 Git 忽略。`enabled=false` 只关闭模型请求，本地行为仍运行；配置最多缓存 10 秒。构建版本从 `Application.persistentDataPath` 读取同名文件，密钥不进入 Assets 或版本库。

默认模型 `deepseek-flash`，非思考模式、JSON 输出。只发送游戏给出的性格、天气、疲劳、玩家距离和候选动作，不发送聊天记录或存档内容。请求最多同时一个，全局间隔至少 10 秒，单只动物至少 90 秒，超时 12 秒。仅附近 24 米内的动物申请模型决策。

## 行为与边界

- 动作包括恢复原活动、避雨、靠近玩家、短暂跟随、保持距离、睡觉。模型最多排列三个已提供的选项，不能生成坐标、执行代码或创造能力。每一步执行前重新核对可用动作。
- 网络请求期间继续当前活动。玩家互动、天气变化和控制器目标变化会使旧模型计划失效；群体路线规划另行核对身体能力和地形版本，局部路线始终在执行前检查真实通行条件。超时、空回复、截断回复或白名单之外的结果不接管行为。
- 内外向由种子和个体标识稳定决定，外向概率约 20%。外向动物仍保留物理间距，会靠近或短暂跟随。普通动物保留既有惊吓反应。
- 按已讨论的“雨变大”场景，强雨触发避雨，弱雨保留日常活动。避雨选择附近候选遮蔽处，经真实身体／地形查询寻找路径；被占据或不可达目标会跳过或暂时记为失败，雨停或转弱释放避雨目标。普通动物恢复先前活动，离队成员返回群体当前地点。
- 白天允许疲劳小睡，夜晚提高睡眠倾向、延长睡眠；狐狸使用相反的昼夜倾向。已有趴下／睡眠／起身动画继续使用，缺少完整睡眠动画的动物先以静止打盹加 Z 表示，**未新增各物种趴卧动画**。
- 白色圆角 Z 由三个复用的线条对象升起，醒来即隐藏，远处不显示；没有每帧生成文字或实例化粒子。
- 临时离队成员不参加新一轮群体路线分配。群体规划允许成员继续移动，应用前从当前姿态重新核对衔接。桥、水边和障碍前必要的安全等待仍保留。

## 计算与寻路

普通动物 Think 按个体错峰，行为工作与局部绕行共享每帧约 2 ms／最多 8 个启动单元的软预算。单次 Unity 物理查询无法在中途抢占，因此这不是硬性的帧耗时保证；移动与碰撞检查继续逐帧运行。

参考 Voxel-Resort 的网格 A* 与二叉堆结构实现了 `AnimalLocalRoute`，用于邻近陆地目标。每个工作单元最多执行一次完整身体通行查询，最多展开 512 个节点，不使用原项目有穿墙问题的视线平滑。原有 `JourneyNavigation` 继续负责跨桥、涉水、游泳距离和复杂身体支撑，未被原项目二维网格整体替换。

当前树下遮蔽候选来自带 LODGroup 的树木渲染范围，屋檐来自物理探测，生活点来自已有 sheltered 标记。树冠范围属于场景几何近似，不是逐叶雨滴遮挡模拟；较远或未带这些信息的树木仍需后续场景标注。局部搜索不能保证所有地图目的地可达，失败时保持本地安全行为，不瞬移。

## 验证

- 全部运行时代码和新增检查完成 C# 编译。
- 独立 Unity 工程执行动作协议、过期回复、稳定性格、A* 绕墙、玩家优先、睡觉、避雨恢复、队伍移动规划等检查，并回归既有普通动物、桥梁／游泳和群体间距检查。参见 `contracts.txt`。
- 将旧的“成员位置一变就使规划失效”条件重新放回独立副本，回归用例按预期失败；修复版本通过。参见 `regression-red.txt`。
- 独立 Unity **Play** 验证自动登记、真实 Update 移动到遮蔽处、雨停恢复、疲劳睡眠、Z 生命周期和互动唤醒。参见 `play.txt`。
- 独立相机渲染检查了白色圆角 Z。`sleep-z.png` 是特效验证图，不是主场景截图。
- DeepSeek 实际接口收到合成雨天情境后返回 `shelter`，单次约 3.2 秒。参见 `provider-probe.json`。该延迟不代表稳定网络表现或游戏帧率。

未打开、保存或切换主场景的 Play 状态。主场景全量动物的帧时间、长时间拥挤路线和所有物种的视觉表现仍需现场验收，不能用独立用例结果替代。

复验命令：`Tools/AnimalAI/Compile.ps1`，`Tools/AnimalAI/Run-UnityChecks.ps1 -Mode Contracts`，`Tools/AnimalAI/Run-UnityChecks.ps1 -Mode Play`。后两项仅操作 `Temp/AnimalAIValidation` 中的独立工程，不复制场景、存档或密钥。

接口依据：[DeepSeek 非思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)、[JSON 输出](https://api-docs.deepseek.com/guides/json_mode/)。
