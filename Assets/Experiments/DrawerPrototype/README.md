# P2 立体抽屉原型

入口在 **Unity 编辑器顶部菜单栏**：`Weather House → 试玩 → 抽屉翻找原型（P2 立体版）`。

- 从正俯视向前倾斜约 12° 的正交相机，以木框中心取景，露出少量侧面，保留抽屉比例。遮挡判断与点击均沿当前相机视线进行。
- 26 封有厚度、有刚体和碰撞体的信件。长按约 0.12 秒后直接跟随鼠标，通过物理接触推动周围信件，松手后恢复自由落下；信封始终留在抽屉内。
- 按下信封立即出现暖金色呼吸轮廓光，拖动期间保留，松手或失去窗口焦点时清除。
- 信封使用现有手账纸张纹理及法线，带低对比植物压纹、灰草绿叶纹火漆。火漆、书封、镜头和木板接受实际灯光。
- 抽屉放在草地上。直接引用正式 WatersideV2 的短草、长草、白色雏菊网格、材质、风动和地表资源，使用独立的小块地形；木框附近使用原系统的压低短草通道。周围不再生成桌面或装饰枝条。
- 草地边缘保留 `R10_OrangeFlower` 和穿插的 1.55–1.75 倍雏菊；按最新反馈移除蕨类和圆叶地被。装饰不带碰撞体，不拦截信件点击。
- 正下方仅显示与魔法书练习页一致的鼠标线稿，首次拖动后隐藏；不再显示文字说明。
- 五件可收集道具：魔法笔记、字典、相机、魔杖、带小狗照片的奶奶来信。
- 翻出道具主体后点击拾取；中心放大和魔法反馈；关闭纸签后收进右侧，点击可重读。
- 独立保存已收集、已阅读状态；重新进入时纸张重新摆放。

这是立体交互与画风原型。当前完成五件道具后显示准备出发，尚未接到正式地图及正式物品系统。信纸采用刚体，暂不做纸张弯曲或布料模拟。相册任务书模型已单独制作，不属于抽屉收集物。

Unity 顶部菜单 `Weather House → 抽屉原型 → 画面调参面板` 打开独立窗口，可放在 Game 视图旁边。未试玩时点击“开始抽屉预览”。窗口提供草地密度、种子和三种草花的撒点权重，草地颜色、风、法线、明暗边界，信纸正面／折面和书封的油画笔触，以及阳光、环境补光和投影参数。另可单独开启已有的全画面油画后处理和左右对比，默认关闭。

信纸与两种书封复用 `Weather House/Oil Paint Surface` 和原笔触图集，保留纸张／布面原纹理。当前油画 Shader 使用厚涂法线，不支持原 Lit 材质的纸张法线贴图。

在“纸张 / 书封”页的“调整对象”中，可分别选择普通信封正面、普通信封折面、奶奶信纸、魔法书封和字典书封。奶奶信纸使用独立的 `Look/LetterPaper.mat`，随原有“保存为抽屉默认值／恢复已保存值”一起保存和恢复；照片仍保持已确认的绘本配色。普通信封和书封沿用已有的调参值。

Play 中调整立即生效，点击“保存为抽屉默认值”写入本目录 `Look/DrawerLook.asset` 及专用材质；“恢复已保存值”放弃本次未保存试调。运行时使用材质副本，退出 Play 后丢弃未保存变化。抽屉使用私有 URP 配置承载后处理，退出时恢复原管线；不会修改正式地图的材质或项目渲染设置。三本书仍使用太阳、条目、照片标记。

`Models/` 中提供可直接拖入场景的外观 Prefab：`MagicBook`、`Dictionary`、`AlbumTaskBook`、`Camera`、`Wand`。各自的网格和材质保存在同名 `Parts.asset`，保留纹理引用；这些外观资源不绑定抽屉的收集逻辑。相册任务书不在抽屉里生成可收集物。已保存的 `LeafBranch` 和 `GrassSprig` 模型仍保留，当前草地场景不使用它们。

2026-10-29 新增 `Models/CameraV2.prefab` 和 `Models/GrandmotherLetter.prefab`。相机包含分层镜筒、对焦环刻度、凸面镀膜玻璃、取景窗、旋钮与背带环，配细纹皮革和缎面金属；网格合计 12,912 三角形。奶奶来信采用有厚度、轻微翘边的纸面，照片卡与金属夹均为独立模型。抽屉中的两本书、普通信封和已保存的画面参数保持原值。
