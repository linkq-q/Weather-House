# P2 立体抽屉原型

入口在 **Unity 编辑器顶部菜单栏**：`Weather House → 试玩 → 抽屉翻找原型（P2 立体版）`。

- 完全俯视的正交相机，以抽屉中心取景，左右、上下分别等距，保留抽屉比例。
- 26 封有厚度、有刚体和碰撞体的信件。长按约 0.12 秒后直接跟随鼠标，通过物理接触推动周围信件，松手后恢复自由落下；信封始终留在抽屉内。
- 按下信封立即出现暖金色呼吸轮廓光，拖动期间保留，松手或失去窗口焦点时清除。
- 信封使用现有手账纸张纹理及法线，带低对比植物压纹、灰草绿叶纹火漆。火漆、书封、镜头和木板接受实际灯光。
- 抽屉放在草地上。直接引用正式 WatersideV2 的短草、长草、白色雏菊网格、材质、风动和地表资源，使用独立的小块地形；木框附近使用原系统的压低短草通道。周围不再生成桌面或装饰枝条。
- 五件可收集道具：魔法笔记、字典、相机、魔杖、带小狗照片的奶奶来信。
- 翻出道具主体后点击拾取；中心放大和魔法反馈；关闭纸签后收进右侧，点击可重读。
- 独立保存已收集、已阅读状态；重新进入时纸张重新摆放。

这是立体交互与画风原型。当前完成五件道具后显示准备出发，尚未接到正式地图及正式物品系统。信纸采用刚体，暂不做纸张弯曲或布料模拟。相册任务书模型已单独制作，不属于抽屉收集物。

在原型根物体的 `DrawerPrototypeController` 上可以调整 `Live lighting` 参数：光照强度、太阳高度与方位、阴影强度、阳光和环境光颜色。Play 中立即生效；要保留数值，在退出 Play 后填写到独立原型场景并保存该场景。三本书使用太阳、条目、照片标记。

`Models/` 中提供可直接拖入场景的外观 Prefab：`MagicBook`、`Dictionary`、`AlbumTaskBook`、`Camera`、`Wand`。各自的网格和材质保存在同名 `Parts.asset`，保留纹理引用；这些外观资源不绑定抽屉的收集逻辑。相册任务书不在抽屉里生成可收集物。已保存的 `LeafBranch` 和 `GrassSprig` 模型仍保留，当前草地场景不使用它们。

`Weather House → 抽屉原型 → 运行交互检查` 会创建独立测试存档，走运行时指针输入路径并保存真实 GameView 截图；不会覆盖普通试玩的原型进度。

测试与截图在项目根目录 `DrawerPrototypeReview`。退出 Play 后恢复之前的启动场景；正式场景不由该原型保存。

木纹和布面底色由内置 image_gen 制作，物体的厚度、倒角、纸张折面、火漆、植物和阴影由 Unity 实时渲染。纸纹、纸张法线、字体及轻纸张/成功音效复用现有项目资源。被替换的背景图留在 `DrawerPrototypeReview/retired-art`，不进入运行时 Resources。

自动检查通过运行时指针处理器操作真实物理对象，并截图 GameView；自动检查不等于真人手感或美术验收。

2026-10-29 抓取回归验证：旧版同一操作的移动误差约 38.5 像素、停手误差约 29.6 像素；新版两项均小于 1 像素。这是自动指针与固定物理帧下的比较，不代替真人手感判断。完整翻找、推挤、边界约束和五件道具收集通过，记录在 `DrawerPrototypeReview/checks-20261029-021547`（目录按 UTC 命名）。

同次重进检查通过，收集与已读状态恢复，纸张重新生成。最新草地、居中、呼吸边缘和光照比较的实机图在 `DrawerPrototypeReview/meadow-20261029`。正式场景及引用的 17 项草地资源校验值未变，退出 Play 后恢复原场景和 Dirty 状态。
