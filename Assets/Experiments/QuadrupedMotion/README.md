# 小羊、小鹿四足动作

在 Unity 菜单打开 **Weather House → 小羊小鹿四足动作预览**，无需进入 Play。上方选择动物与动作，支持暂停、时间滑条、播放速度、前面/侧面视角、右键旋转和滚轮缩放。

每只动物各有六条独立 FBX：行走、小跑、奔跑、转身、低头嗅闻、跳跃，位于 `Models/sheep` 和 `Models/deer`。使用 Generic 骨架，原始单高光贴图在 `Textures`；原 PNG 保持 8K，Unity 导入尺寸为 2048。

这批使用两套新建的四足蒙皮骨架，各 25 根变形骨。动作由本机 UniMate 一次加载、逐条生成，每条 60 帧。预览采样原始动作，仅统一展示位置和镜头，没有添加松鼠的双足步态修正、尾巴波浪或弹性增强。

短片结尾直接回到开头；本批用于比较生成效果，未逐条修复脚滑、穿模、动作语义或循环接缝。可在动画时间滑条中停到任意帧检查。

首批逐帧筛查发现：小鹿行走接近待机，两只动物低头嗅闻幅度偏弱；小羊行走的前腿摆幅弱于后腿，跳跃偏轻弹。小鹿奔跑和跳跃幅度较明显。详细指标与局限记录在下述实验目录的 `检查/首批动作观察.md`，自然度仍需要看实际预览判断。
