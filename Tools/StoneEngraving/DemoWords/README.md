按最终策划定稿制作，喜欢不制作石碑。只新增独立资产与预览；不修改七块现有石碑，不保存主场景，不改动物 AI、词库和进度逻辑。

当前状态：三块独立 Prefab 与近看、侧看、俯视渲染可审阅。“以前”按用户选定的②湖西岸圆台遗址制作，图案为完整拱门、圆形石台和湖岸，配正式字形。用户否定偏肩碑体后，模型改成拱形外轮廓、内凹刻画面、宽石边和厚基座；彩绘源图及标准字形不变。此前回忆泡、天气变化、成长方案全部弃用。新 past 图意需要与遗址成对出现，尚未获本轮视觉验收，也未摆入主场景。

## 字形与材质

标准字形来自桌面「字符设计/动物语字符设计_v05_四字扩展_20261030」的 SVG 和 PNG，保存原件及 SHA-256。白色图画线条生成技术深度、法线和 AO；彩色原图逐字节保留。字形只进行栅格缩放及受拓扑检查保护的增粗，保留连接部件和内部空隙，线宽不低于图画。

沿用 Seven Mineral Paint Shader、原 HIGHLANDS 灰石法线和 PaintGrain。根据用户“外形同质化”的反馈重新制作三种轮廓和基座比例，仍采用已确认风格的闭合削角低多边形网格，每块不超过 200 三角面、三个 MeshCollider，地面枢轴。保留原 StoneEngravingReadability，照片视角不开启俯视增强。

每个 Prefab 配置实际生产 LifeGlyphInscription 脚本 GUID：ID 为 stone.sea、stone.look、stone.past；字序列各为对应单字；Renderer 指向正文面，readingFace 的局部 +Z 朝外（碑体 -Z），readingSize 依据实际图字覆盖包围盒，仅留 2.5cm 余量，独立于底座。九个读取采样点均检查命中实际碑面。隔离项目只用同 GUID 的字段替身制作序列化引用，不复制该替身进主项目；生产拍照桥及入手账行为由集成任务负责验证。

## 复现和验证

1. 运行 `prepare.py`：只在 `StoneEngravingReview/20261030/DemoWords/UnityProject` 建立独立项目，生成技术贴图。含图像边界、字形拓扑及粗细断言。
2. 用 Unity 2022.3.62f3c1 批处理执行 `DemoStoneBuilder.Build`。不加 `-nographics`。输出近看、斜看、游戏参数俯视各三张。
3. 查看九张渲染、`Renders/checks.txt` 与 `map-checks.json` 后运行 `package.py`。只复制 DemoWords 独立资产到主项目，不导出隔离项目的依赖 shim、渲染管线或场景。

隔离预览使用原可读性组件和一个仅供渲染的 GameplaySession 依赖替身，以控制游戏/照片分支；它不会进入主项目，不能作为主场景运行验证。俯视默认参数取自 WatersideSceneBuilder：俯角 43°、距离 18m、FOV 35°；这里只对准单碑，非最终角色站位。

验收：三块正式字形存在，图画与字形刻槽采样全部落在平面，闭合网格且无零面积三角形，每块不超过 200 三角面，碰撞/可读性/碑文配置齐全，源图与 SVG 哈希不变，九张渲染均含彩色图案。最终含义辨识、地形遮挡和拍照距离待用户场景试玩确认，尤其“以前”不能误读为想要或先后计划。
