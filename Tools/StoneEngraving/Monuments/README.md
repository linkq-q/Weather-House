# 四块宏伟碑体重制

针对用户圈出的「先与后、这里与那里、一起、草与树」重做模型。另三幅与主场景中的原石刻保留。

## 造型

- 先与后、这里与那里：横向墙式壁碑，连贯的整块阅读面。
- 一起、草与树：收肩冠顶、直立的纪念碑轮廓。
- 共同结构：削角石身、厚实侧壁、两层低矮基座；每块 162 个三角面，三块闭合静态网格。
- 新模型由编辑器工具确定性构建；风格依据现有 HIGHLANDS 低多边形造型与雨水石材质。不是原包内现成模型。
- 白色刻槽、矿物彩绘、动物字和纹理配准完全复用上一版。新碑面降低石材法线强度，以免大折痕干扰阅读。

## 交付与复现

独立 Prefab 在 `Assets/Experiments/StoneEngraving/MonumentPainted/`，带静态 MeshCollider、地面枢轴与原可读性组件。

Unity 编辑态向 `StoneEngravingReview/20261030/command.txt` 写入 `monuments`，由 `StoneMonumentStudy.Build` 生成四块及人物比例、正面、侧面、空白、俯视五组渲染。它只使用独立 PreviewScene，不修改或保存主场景。

运行 `package.py` 验证受保护文件哈希、原图案引用、配准与截图数量，并生成桌面 `20261030_宏伟石碑重制/宏伟石碑预览.html`。预览含上一版对照。

## 验证边界

闭合网格检查、零面积三角形检查、原始刻纹采样落面检查均在生成时执行。截图是实际 Unity 编辑态渲染；未运行 Play，也未替换主场景。最终位置、相机距离与玩家对线索的理解需场景试玩确认。

## 用户确认后放入主场景

用户随后确认四块造型并要求放入场景，位置与大小由用户亲自调整。`place-monuments` 命令在干净的 WatersideV2 编辑态执行一次；创建「宏伟彩绘石碑 · 可调摆放」组，四个子物体为连接原资产的 Prefab 实例，初始缩放为 1。

初始位置沿用对应旧石刻包围盒中心的 X/Z，碑体保持直立并继承旧画面的水平方向，基座按地形落地。旧四块仅隐藏，保留原变换和 Prefab；其他石刻不动。场景会保存，工具拒绝覆盖已经摆放的新组，防止再次运行冲掉用户调整。

`StoneEngravingReview/20261030/Monuments/MainScene/` 保存放置前完整备份、四张场景截图和验证报告。由于主场景在本次之前已有其他未提交修改，仅将本次前后差异另存 `placement.patch` 纳入独立提交；主场景已在磁盘保存，不把此前修改混入本次提交。
