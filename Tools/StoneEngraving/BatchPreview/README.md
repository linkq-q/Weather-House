# 七张石刻的选石覆盖预览

用户要求先确认石形和图案覆盖，再决定是否制作与入场景。这里仅输出独立 Unity 渲染预览，没有新增主项目材质、预制体或场景物体。

1. `generation.json` 记录内置 ImageGen 的七份参考图与提取要求。`Source/` 保存生成的黑白线稿。图意沿用原概念图，字形不交给生成模型绘制。
2. `prepare.py` 用项目 `AnimalGlyphsV04` 原始 alpha 排布动物语，生成线稿覆盖数据，记录字形 SHA-256，复制 17 个候选网格到原独立验证工程。输入缩放保持比例，图案和字形作为整体留边。
3. 在 `StoneEngravingReview/20261029/UnityProject` 中运行 `StoneApprovalBuilder.Run`。它以真实网格射线筛选连续刻面、按版面比例和居中程度排序，在可用面积相近时选不同石形。只使用旋转与均匀缩放，不改网格顶点。四周留余量，逐笔画采样验证表面存在且朝向可阅读。
4. `package_preview.py` 将未修图的 Unity 渲染打包到桌面 `天气屋/20261029_七块石刻_选石覆盖预览`，附总览与离线大图画廊。

输出 `selection.json` 包含实际选用网格、旋转、覆盖矩形、三角面和建议尺寸。每张有空白石头、正向覆盖、斜向覆盖、俯视缩略与 `coverage-check.txt`。射线采样检查不等于人类语义验收；“草与树”的树干与鹿背连接、“强与弱”的差别大小均保留给用户审图。

预览材质只显示线稿，不代表最终凹槽深度、崩边与光照；使用几何面法线展示 lowpoly 折面。既有石刻的俯视增强与拍照原样效果保持不变。主场景摆放、照片识别和最终远近可读性在用户确认后再做。
