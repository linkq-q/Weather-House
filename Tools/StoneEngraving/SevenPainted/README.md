# 七块彩绘石碑

沿用用户选定的雨水石彩绘：暖白刻槽、低饱和矿物色、细微干刷颗粒。内置 image_gen 逐幅编辑现有线稿；完整提示词与生成路径在 generation.json。图片原样复制到项目，未通过 Python 修改图像。

全部模型来自与雨水石相同的 HIGHLANDS 资产包：Stone_1 斜顶石板和 Stone_2 方形石板，按构图调整比例并立起。不是新生成的独立美术风格模型。石材底色与凹凸纹理复用原雨水石材质。

- 风：中等斜顶碑，保留旗杆和底部字。
- 湿与干：中宽方碑，左右布匹、雨点、动物字完整。
- 强与弱：较宽方碑，两个角色的衣服及旗子配色一致，保留风线数量表达区别。
- 草与树：较高斜顶碑，为上方和下方的动物字留足空间。
- 先与后：宽叙事碑，三幅连续画面；羊统一米白，避免与狐狸混色。
- 一起：中宽斜顶碑，叶子及四只动物完整。
- 这里与那里：横向方碑，两个水面、虚线箭头及下方动物字完整。

所有资产位于 Assets/Experiments/StoneEngraving/SevenPainted，保留原七幅刻槽 Mask/Normal 及动物字，不改原场景或原素材。每块有独立 Prefab、静态 MeshCollider、地面枢轴和已有 StoneEngravingReadability 组件。

## 重现

运行 prepare.py 计算原画布到刻槽布局的仿射 UV（读取图片尺寸和边界，不编辑图片），然后将 generation.json 中的最终图片原样复制到对应资产路径。Unity 编辑态向 StoneEngravingReview/20261030/command.txt 写入 seven-painted；工具会在独立 PreviewScene 渲染七组正面、侧面、空白石形、俯视缩小图并保存 Prefab。运行 package.py 生成桌面「20261030_七块彩绘石碑/彩绘石碑预览.html」。

## 验证边界

checks.txt 逐刻画采样点验证落面，包含动物字，无缺失或落在陡边。package.py 核对原场景和原七幅资产哈希、复用的刻槽图、原雨水石表面纹理、UV 边界对应关系及28张渲染图。主场景未替换，未执行 Play。人类是否能正确理解图中线索仍需用户试玩确认；俯视缩小图用于发现目标，近景用于解读。
