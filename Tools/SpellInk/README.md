# 施法笔迹与 G 图标

游戏中的入口是左下角 G 魔杖图标或键盘 G，再次点击／按 G 退出，Esc 收起。白天采用白金光晕，WatersideMood 夜间采用青绿流光。主笔迹半径是已确认预览参数的 3 倍；星尘仍保持细小。现有项目没有连续运行的 TOD，这次接入现有日夜状态，效果组件保留 0–1 的 Daylight 参数。

世界施法与魔法书实际练习共用流光效果；手账固定图示和自动示范保持纸上笔迹。圆头线段先用 Max 合成，再作为预乘 Alpha 图层绘制，避免折角重复叠亮。失败保留暖橙色反馈，识别输入和施法结果不变。

松开后，笔迹按不同节奏收拢成圆润光点，再分为少量明亮主流萤、中层伴随光和细星尘。每颗粒子独立变化延迟、寿命、尺寸、亮度、方向与弯曲幅度；运动缓起缓停，亮度柔和出现、短暂停留后非线性渐隐。随机数使用组件自身状态，不改变游戏全局随机序列。日光版提高光点尺寸与亮度，夜间保留青绿与暖金的细微变化。

收尾由实际最后一颗粒子的结束时间控制，替代固定 2.2 秒截断。练习成功后的书页刷新等余光结束，但书写输入锁立即释放；重画、擦除、越界、关书及取消仍可正确清理。粒子总数上限 420，其中书写星尘最多占 160，给消散层留出空间。

G 图标依据现有 Camera、MagicBook、DictionaryBook、PhotoTasksBook 的实心白色剪影风格制作，显示为 44×44，按钮热区为 72×86，沿用 HUD 浅米色。运行 `python Tools/SpellInk/build_icon.py` 可生成原生透明 PNG。

## 验证

2026-10-29 已通过 C# 编译和独立 Unity 2022.3.62f3c1 GPU 检查。178 条断言（包含逐粒子的曲线端点检查）覆盖三层尺寸与密度、随机延迟与寿命、渐隐曲线、3 倍粗度、直角／锐角／回折、最终 UI 合成、结束及取消后的透明像素、六种手势识别、G 图标与模态，以及 shader 编译。证据在 `SpellInkReview/20261029-firefly/gpu/`。

在 Unity 编辑器顶部菜单运行 `Weather House > Life > Check spell ink` 可复核 GPU 检查，必须处于非 Play 状态。它创建并关闭临时预览场景，不保存游戏场景。输出位于 `SpellInkReview/20261029-firefly/`。

主编辑器被其他工作占用时，可运行 `python Tools/SpellInk/prepare_review.py`，它用本机 Unity 编译器检查当前源文件，并生成任务专用的小型验证工程。然后用 Unity 对该工程执行 `WeatherHouse.Life.Editor.LifeSpellInkChecks.RunBatch`；批处理输出位于这个小型工程内部的同名目录。准备脚本沿用本项目 Unity 安装位置及 Bee 响应文件路径，版本迁移时需更新。

主场景 Play 复测也已通过，证据在 `SpellInkReview/20261029-firefly/play-20261029-075722341/`。实际 G 按钮进入日夜施法，原识别器触发雨／晴，完整消散后退出并释放渲染纹理；真实练习页的指针处理器完成学习，验证余光保留、重试、越界、关书及再次施法取消。GameView 的日夜书写、凝聚、游散和练习截图均已检查。输入轨迹由测试程序驱动，这不等同于真人鼠标手感或性能验收。

重跑入口在 **Unity 编辑器顶部菜单栏**：`Weather House > 试玩 > 施法流萤检查（独立存档）`。先打开 WatersideV2，退出其他 Play／试玩并等编译结束。检查使用独立存档，保留脏场景副本，不切换或保存正式场景，结束自动退出 Play 并核对原场景和三个正式存档的哈希。最终交还状态为 Play=False、Dirty=True。编译只有项目既有 PainterlyWaterReflection 过时 API 警告。
